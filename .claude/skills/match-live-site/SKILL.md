---
name: match-live-site
description: Use when building any UI so it matches the look and feel of globalproptechsummit.com.
---

1. Read docs/design-system.md.
2. Open the live site in the browser tool and screenshot the relevant area into references/.
3. Inspect computed styles (color, font, radius, blur) instead of guessing.
4. Use tokens from src/styles/global.css; if one is missing, add it and update the doc.
5. Compare the result with the reference at 1440px and 390px wide.
